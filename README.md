An entry for make.fun's [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty ($2, 1st $1, 2nd $1). ## The line

> I asked the AI to write my will. It left everything to the cloud — including me.

80 characters, one line. The turn is the AI treating the cloud as the heir — and the narrator as part of the estate, not the one leaving it.
